# Бот «VK + Яндекс Диск»

Бот ВКонтакте: по тексту-запросу находит файлы на Яндекс Диске по названию
и присылает без дублей (по имени).

## Возможности (текущий каркас)
- Поиск по почти любому названию (fuzzy через `difflib`, есть точный режим).
- Рекурсивный обход папок диска.
- Дедупликация по нормализованному имени (снимает « (1)», пробелы, регистр).
- Приём сообщений через VK Bots Long Poll.
- Отправка ответа ссылкой на скачивание (вариант «ссылкой»). Для отправки
  «файлом» (вложением в ВК) — см. TODO в `vk_bot.send_doc`.

## Зависимости
- Python 3.11+
- `requests` (одна внешняя библиотека)

Установка:
```bash
python3 -m venv venv
venv/bin/pip install requests
```

## Настройка (.env)
Скопируй `.env` и заполни:
- `YANDEX_DISK_TOKEN` — OAuth-токен Яндекс Диска (владелец диска).
  Получение: https://cloud-api.yandex.net → «Ключ» → «Получить OAuth-токен».
  Нужны права чтения диска.
- `VK_ACCESS_TOKEN` + `VK_GROUP_ID` — токен группы и id сообщества.
  Создай группу ВК → «Сообщения» → «Сообщения сообщества: Вкл» → Long Poll Access Token
  (кнопка «Возможности бота», включить Bots Long Poll).

`.env` в `.gitignore` — не коммить.

## Запуск (локально)
```bash
venv/bin/python3 bot.py
```
Лог: «Слушаю Long Poll...».

## Развёртывание 24/7 (VPS)
Скопируй проект в `/opt/vk-yadisk-bot`, затем:
```bash
sudo cp vk-yadisk-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now vk-yadisk-bot
sudo journalctl -u vk-yadisk-bot -f
```

## Проверка поиска без бота
```bash
YANDEX_DISK_TOKEN=... python3 disk_search.py 'договор'
```
